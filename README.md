# 📊 Excel Sales Analytics Dashboard

## Project Overview

This project demonstrates an end-to-end sales analytics workflow in **Microsoft Excel**, transforming raw transactional data into a professional interactive dashboard capable of supporting business decision-making.

The project follows the complete data analytics lifecycle:

- Data Cleaning
- Data Validation
- Feature Engineering
- Exploratory Data Analysis
- Business Intelligence Dashboard Development
- Business Insights & Recommendations

The objective was to convert raw sales data into meaningful KPIs, trends, and visualizations that enable stakeholders to monitor business performance and make informed decisions.

---

## 🎯 Project Objectives

The dashboard was designed to answer key business questions such as:

- Which regions generate the highest revenue and profit?
- Which salespeople contribute the most revenue?
- Which SKUs are the biggest revenue drivers?
- How do discounts affect profitability?
- What are the monthly sales trends?
- Which product categories perform best?
- What is the Average Order Value (AOV)?
- Which products should receive the most business attention?

---

## 🧹 Data Cleaning & Preparation

The dataset was cleaned and standardized before analysis.

### Cleaning Tasks

- Removed duplicate records using Excel's **Remove Duplicates** feature.
- Converted Order Date and Required Date into a consistent date format.
- Converted Unit Cost, Unit Price, Quantity, and Discount Percentage into the appropriate data types.
- Removed records containing missing values.
- Corrected inconsistent formatting across the dataset.
- Verified data quality before beginning analysis.

---

## ✅ Data Validation

Several validation checks were performed to improve data quality.

These included:

- Identifying negative Unit Prices.
- Recalculating incorrect selling prices.
- Validating Discount Percentage values.
- Correcting invalid discount values.
- Identifying Required Dates occurring before Order Dates.
- Correcting inconsistent records using Excel IF formulas.
